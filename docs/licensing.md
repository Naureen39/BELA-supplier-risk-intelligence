# Licensing register

This register records what the project depends on and the terms attached. It is a summary for engineers, not legal advice:
have counsel review it before commercial use or redistribution.

## This project

No license file has been added yet, so by default all rights are reserved by the author. Choose a license before
inviting others to use or contribute. Constraints from the list below that bear on the choice: none of the dependencies
requires the project to be open source; the LGPL packages are used unmodified as libraries.

## Fonts, images, and icons

- Inter and JetBrains Mono through `@fontsource` (SIL Open Font License 1.1), self-hosted.
- No third-party photographs: all visuals are drawn in-house. Any future photograph must be recorded in
  `apps/web/public/images/CREDITS.md` first.
- Map shapes: US Census cartographic boundaries (US government work) through the `us-atlas` package, converted by
  `apps/web/scripts/build-geo.mjs`.
